INSTRUÇÕES PARA EXECUTAR O PROGRAMA
=================================================================
EM LINUX:
================================================================
1. Baixe todos os arquivos desta pasta.

2. Abra o terminal na pasta em que os arquivos foram salvos.

3. Instale as bibliotecas necessárias:

python -m pip install -r requisitos.txt

4. Execute o programa:

python orbita_kepler.py

5. O programa gerará os arquivos:
- orbita_kepler.png
- orbita_kepler.gif

Além disso, será aberta uma janela com a animação da órbita.

Observação:
Em alguns computadores, pode ser necessário substituir "python" por "python3".

#===========================================================================
EM WINDOWS:
#===========================================================================
1. Instale o Python pelo site oficial e marque a opção
   **Add Python to PATH** durante a instalação.

2. Baixe todos os arquivos desta pasta.

3. Abra a pasta no Explorador de Arquivos.

4. Clique com o botão direito em uma área vazia da pasta e escolha
   **Abrir no Terminal**.

5. Instale as bibliotecas:

powershell
py -m pip install -r requisitos.txt

6. Execute o arquivo:

py orbita_kepler.py

7. O programa gerará os arquivos:
- orbita_kepler.png
- orbita_kepler.gif
